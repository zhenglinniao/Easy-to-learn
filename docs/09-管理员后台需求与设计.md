# 管理员后台需求与设计

## 1. 范围

首版管理员后台只解决两类运营需求：

1. 动态管理文字模型：新增或移除 Provider、启用或停用、调用顺序、服务地址、模型 ID、接口协议、结构化输出模式、超时和 API Key。
2. 查看最小必要账户数据，并对异常账户执行可恢复的暂停或恢复操作。

后台允许管理员以只写方式新增或替换 AI API Key，但不会回显密钥。Supabase 密钥、密码、Access Token、题目、画布快照、图片或模型回答仍不可见。账户永久删除继续走既有 7 天冷静期流程，管理员后台不提供绕过冷静期的删除按钮。

## 2. 管理员身份

- 管理员必须先是正常 Supabase 登录用户。
- 服务端通过 `ADMIN_USER_IDS` 环境变量中的 Supabase User UUID 白名单判定管理员身份。
- 前端路由和按钮只用于改善体验，所有 `/api/admin/*` 接口都必须重新验证 JWT 与服务端白名单。
- 管理员不能暂停自己的账户。
- 所有模型修改和账户暂停/恢复写入 `security_audit_events`，日志只保存 HMAC 摘要，不保存邮箱。

采用服务端 UUID 白名单而不是邮箱判断，避免邮箱修改、大小写和别名造成提权。首版不建设“管理员创建管理员”的界面，防止单个被盗管理会话继续扩散权限。

## 3. 模型动态配置

Vercel 环境变量是首次启动与 Redis 故障时的回退配置。管理员后台可以保存完整 Provider 链；完整配置在写入 Redis 前使用从 `AI_CACHE_ENCRYPTION_KEY` 派生的独立 AES-256-GCM 密钥整体加密。API Key 只写不读，概览 API 仅返回 `hasApiKey`。

```json
{
  "providers": [
    {
      "id": "deepseek",
      "label": "DeepSeek Flash",
      "type": "openai-compatible",
      "enabled": true,
      "baseUrl": "https://api.deepseek.com",
      "model": "deepseek-flash",
      "wireApi": "responses",
      "responseFormat": "json_schema",
      "timeoutMs": 12000,
      "apiKey": "<encrypted-at-rest>"
    }
  ],
  "updatedAt": "2026-09-26T10:00:00.000Z",
  "updatedBy": "<user uuid>"
}
```

- Redis Key：`ai:admin:provider-config:v2`，值为认证加密密文。
- 至少保留一个已启用 Provider。
- 最多保存 5 个 Provider；启用项必须有 API Key。
- Base URL 必须是 HTTPS 且域名必须位于服务端允许列表。内置允许 `token.sensenova.cn`、`api.deepseek.com`、`api.openai.com`；额外域名使用 `AI_ADMIN_ALLOWED_PROVIDER_HOSTS` 配置。
- 全链路超时仍不得超过 25 秒。
- Tutor 请求每次读取当前策略，因此保存后下一次请求生效，无需重新部署。
- Redis 或策略损坏时采用环境变量默认配置，不能把无效管理数据带入模型调用。

## 4. 账户数据

列表字段仅包括：用户 ID、脱敏邮箱、创建时间、最近登录时间、邮箱确认状态、暂停状态和画板数量。支持分页与当前页邮箱/ID搜索。

允许操作：

- 暂停账户：使用 Supabase Admin API 设置长期 ban；已签发会话的最终失效时间受 Supabase 会话/JWT策略影响。
- 恢复账户：清除 ban。

不允许操作：查看用户内容、修改密码、替用户确认邮箱、立即永久删除。

## 5. API

- `GET /api/admin/overview?page=1&search=`：返回管理员身份、模型策略、当前页账户和汇总数据。
- `PATCH /api/admin/models`：保存完整 Provider 链；`apiKey` 可选，省略或留空表示保留既有密钥。
- `PATCH /api/admin/accounts`：`{ userId, action: "suspend" | "restore" }`。

所有写接口要求允许的 Origin、Bearer JWT、JSON Content-Type，并返回统一错误契约。

## 6. 前端

- `/admin` 独立管理页，未登录引导登录，非管理员显示无权限。
- 顶部显示账户总量、已暂停数量、已启用模型数量。
- 提供 SenseNova 6.8 Flash Lite 与 DeepSeek Flash 安全预设；模型卡片可编辑完整连接配置。
- 本页只配置“画布理解与教学规划”文字/多模态模型；SenseNova U1.5 生图使用独立异步链路，不能伪装成 Chat Completions Provider。
- 账户表格保持高信息密度，危险操作必须二次确认；不使用装饰性动画。
- 移动端改为卡片布局，所有操作保留明确文字标签。

## 7. 验收

- 非管理员和游客不能读取任何管理数据。
- API 概览响应和日志中不存在密钥、完整邮箱之外的额外身份信息、题目或画布内容。
- Redis 泄露时不能直接得到 Provider 密钥；篡改密文会被 GCM 认证拒绝并回退环境配置。
- 管理策略保存后下一次 Tutor 请求使用新顺序、模型名和超时。
- 不能停用全部 Provider，不能暂停当前管理员。
- 暂停与恢复动作可追踪、可恢复且具有审计记录。

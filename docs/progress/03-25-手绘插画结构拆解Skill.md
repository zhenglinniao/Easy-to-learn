# 节点 03-25：手绘插画结构拆解 Skill

## 用户目标

- 任意画布输入都优先转换成原创手绘插画式理解图，而不是生硬文字。
- 学习问题结合题目给出足够详细、没有关键跳步的图文步骤。
- 物体、设备、食物、服装和植物可以按部件、层次、材料、用途或组成进行爆炸拆解与标注。
- 参考图只用于提炼通用视觉方法，不复制作者账号、角色、品牌、文案或具体版式。

## 实现

- 新增并默认启用 Prompt `v5`，保留 `v1`–`v4` 回滚。
- 每一步必须同时包含 `diagram` 与非图解说明块，Domain Schema 拒绝纯文字和只有图片的 v5 步骤。
- 新增 `part-map`：支持 `exploded`、`layers`、`callout` 三种安全布局，部件包含标签、作用、角色和语义色。
- 新增安全 `code` 块，支持常见语言枚举并按纯文本渲染，避免把精确代码交给生图模型。
- 前端新增原创手绘结构拆解卡，继续由产品控制导航、KaTeX、动画、深色主题和 reduced motion。

## 从参考图提炼的视觉语法

- 概念：角色引导 + 中心概念 + 对比/入口 + 一句话总结。
- 组成：主体 + 爆炸部件/层次 + 短标签 + 每部分作用。
- 标注：围绕一个主体按编号或引线解释材料、部件和用途。
- 学习：每个认知台阶展示证据、动作、原因和阶段结果，不用装饰性插画替代逻辑。

## 安全与原创边界

模型仍不能返回 HTML、SVG、CSS、脚本、URL 或交互按钮。参考图中的账号、品牌、角色、Logo、水印、原文和辨识度高的构图不进入项目资产或 Prompt；项目沿用原创“小易”和受控 Tutor DSL。

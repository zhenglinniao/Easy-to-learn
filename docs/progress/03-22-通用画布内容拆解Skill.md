# 节点 03-22：通用画布内容拆解 Skill

## 目标

把画布教学能力从“识别并解答习题”扩展为“理解任意可识别选区并选择最有价值的教育拆解路径”，覆盖文字、手写、文章、食物、蔬果、物体、流程、图表和混合内容。讲解采用准确、轻松、手绘感的分步视觉叙事。

## 调研结论

- OpenAI Skills 采用短入口加按需 references 的渐进披露结构，并建议通过明确的名称与描述完成发现和路由。
- Learning Commons 的公开教育 Skills 使用“静默分类 → 加载领域规则 → 结构化生成 → 质量门禁”的方式，证明领域路由和单一事实来源比超长通用 Prompt 更容易维护。
- 本项目只借鉴结构和工程方法，不复制第三方教学文案、专有模板或 Prompt。

## 实现

- Skill 入口负责证据优先级、模式边界和通用不变量；新增意图路由、视觉叙事、质量与安全三个按需参考文件。
- 新增 Prompt `v3` 并设为默认，保留 `v1/v2` 回滚。
- 新增 `contentProfile`：内容类型、学习目标、目标来源与置信度。Prompt `v3` 的三种模式都必须输出该字段，旧版本不得携带。
- 有明确问题时严格跟随；没有问题时只选一个主要默认路径。例如成品食物偏菜谱与变化过程，蔬果偏营养并可辅以生长，文章偏主旨—证据—含义，物体偏部件—机制—用途。
- `learningGoal=solve` 继续使用已确认的简单题先结论、推理题后答案策略；非求解内容禁止输出 `answerPresentation`。
- 手绘质感、吉祥物和动效继续由前端负责；模型只提供安全的图表、列表、公式、提示框和短文关系，不输出任意 HTML/SVG/CSS。
- 营养、食安、危险操作、健康、敏感主题和视觉识别不确定性增加专门边界；幽默为可选记忆辅助，不能凌驾于准确性与尊重。

## 待验证

- 使用多模型、多模态黄金集验证习题、文章、菜肴、蔬果、物体、流程、图表、混合内容和低置信度输入。
- 真实 Provider 结果需检查路由正确性、事实准确性、图示信息量、幽默克制程度与格式通过率。

## 本地验证

- `skill-creator` 官方快速校验通过。
- Prompt 注册表定向测试与 Tutor DSL 跨字段测试通过。
- 完整质量门禁通过：22 个测试文件、99 个测试用例，Lint、TypeScript、数据库静态检查、生产构建和格式检查全部通过。
- 高危依赖审计无已知漏洞。

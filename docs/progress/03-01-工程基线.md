## 兼容性决策

- TypeScript 从设计初稿 7.0.2 调整为 6.0.3，见 ADR-001。
- 对 Excalidraw 的高危传递依赖应用精确安全 override，见 ADR-002。
- Excalidraw 的 React 19 peer 声明有效；旧 Radix 子依赖缺少 React 19 声明，通过精确 peer policy 接受，真实行为在节点 2 验证。

# 节点 03-23：生产 AI 与手绘辅导板验收

## 本节点完成

- DeepSeek `deepseek-flash` 从仅保证 JSON 的 Chat Completions 配置，升级为 Responses API + JSON Schema + PNG/JPEG 图文输入。
- 默认关闭 DeepSeek thinking，避免教学交互把时间消耗在隐藏推理上；Provider 超时与一次格式纠错边界保持不变。
- 纠错提示携带最多 8 条 Zod 路径与错误消息，使模型能修正具体字段，同时不回传用户原文或图片。
- Explain step 增加父辅导板标题和已验证目标步骤，解决只传 ID 时模型无法保持上下文一致的问题。
- 修复浏览器默认 `fetch` 被作为对象方法调用造成的 `Illegal invocation`，并修复“准备摘要遮挡请求错误”。
- Tutor UI 补齐几何标签、角的双射线、坐标网格/刻度、线段标签与真实流程边；增加内容路由标签、原创“小易”表情、纸张网格和克制的首次出现动画。
- 深色主题为 info / warning / success callout 提供独立高对比配色。

## 动效审查

| Before | After | Why |
| --- | --- | --- |
| 图示用 `stroke-dashoffset` 长距离绘制，触发绘制开销 | 改为 420ms 的 `opacity + transform` 解释性揭示 | 保留“逐步出现”的教学目的，只动画合成属性 |
| reduced motion 完全移除所有反馈 | 保留 160ms 纯透明度淡入，移除位移动画 | 尊重减少运动偏好，同时避免内容突现 |
| 高频步骤切换可能叠加内容动画 | 步骤切换保持即时，仅按钮保留 120ms 按压反馈 | 高频操作优先响应，不用装饰性运动拖慢学习 |

## 验收证据

- 真实 DeepSeek：简单方程、无问题番茄、128×128 PNG 图文请求均通过完整 TutorService 与 Tutor DSL 校验。
- 浏览器：游客画布创建文字、选择、Solve、辅导板展示、下一步、浅色/深色、reduced motion 均完成；控制台 0 error、0 warning。
- 辅导板组件截图确认 390px 宽度下标题、路由、流程关系、反馈与步骤导航无溢出。
- 完整质量门禁通过：22 个常规测试文件、104 个常规测试，Lint、TypeScript、数据库静态契约、生产构建、格式检查和高危依赖审计均通过；真实 Provider 文件含 3 个额外用例，按需运行。

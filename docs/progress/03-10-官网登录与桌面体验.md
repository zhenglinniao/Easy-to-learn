# 阶段 3 / 节点 10：官网、登录与桌面体验

## 交付范围

- 完成公开官网、登录/注册、OAuth callback、画板列表和桌面画布路由；官网不加载 Excalidraw，画布按路由懒加载。
- 登录未配置时保留完整可预览界面并明确禁用真实认证；登录用户访问受保护页面，游客云画板访问均执行安全 redirect。
- 画布接入 IndexedDB 自动恢复和 250 ms 本地持久化；登录用户的云画板在本地事务完成后 3 秒同步资产与快照。
- 云保存通过 BroadcastChannel 竞争单写入者，使用 expected revision；冲突时停止覆盖并保留本地冲突副本。
- AI 菜单接入匿名会话、登录 Bearer、Tutor API 和真实辅导板；超过 1.5 MiB 的选区图片走 10 分钟一次性上传票据。
- 辅导板随画布平移和缩放，拖动距离按 zoom 换算回 scene 坐标；来源移动时跟随，修改或删除时显示 stale/orphaned。
- 支持 light/dark，偏好保存到独立 `easy-to-learn-theme` key，并在应用脚本前同步设置，避免首次渲染闪白。
- 用户栏区分游客、本地保存、待同步、同步中、离线重试、冲突和保存失败状态。

## 可靠性与安全边界

- 游客画板 ID 固定使用 `local_` 前缀，不写 Supabase；云画板必须有登录身份。
- 图片对象路径固定为 `<ownerId>/<boardId>/<contentHash>`，先上传引用资产，再提交快照。
- 云端恢复优先读取无脏写的远端快照；本机存在未同步修改时不会用远端内容覆盖。
- AI 返回仅通过共享 Zod DSL 转为持久辅导板，前端不注入模型 HTML。
- 页面关闭只依赖已完成的 IndexedDB 事务，不等待网络请求。

## 设计工程与动效审查

- 使用 `emil-design-eng` 统一暖白纸张、深墨文字、珊瑚强调色、组件圆角、层级、窄屏布局和可见焦点。
- 使用 `review-animations` 审查交互动效：高频菜单与辅导板不添加入场动画；按钮仅使用 120 ms 的按压缩放和 140 ms 颜色反馈。
- hover 只在精细指针设备启用；`prefers-reduced-motion` 下删除位移反馈，保留颜色状态变化。

## 验证结果

- 自动化质量门禁：格式、ESLint、TypeScript、单元测试、数据库静态契约和生产构建。
- 浏览器回归：首页、登录页、游客画布、light/dark 切换与跨路由偏好保持正常。
- 新增大图票据上传测试，覆盖匿名会话、票据获取、二进制 PUT 和非法 MIME 拒绝。

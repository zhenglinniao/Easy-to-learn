# 阶段 3 / 节点 18：动态图文应用场景

## 状态

已完成。

## 交付范围

- 首页新增独立“应用场景”章节，用中文场景说明配合原创产品微界面，不依赖外部图片或第三方素材。
- “作业卡住时”演示练习册截图、框选局部、选择 Hint 和获得方向性提示的完整顺序。
- “课堂与自学”演示直接绘制几何图、强调已知点以及辅导板贴着原图逐步推理。
- “复习与持续学习”演示画板自动保存、同步状态和在移动设备继续上次进度。
- 每个场景明确适用题型，覆盖数学计算、应用题、理化题图、几何、物理、函数、流程分析、错题整理和长期复习。

## 设计与动效决策

- 使用 `emil-design-eng` 组织图文层级，桌面端交替左右叙事，窄屏统一为“文字在前、演示在后”。
- 使用 `animate` 将动效限定为低频营销说明，目的固定为 Explanation，不给正文和真实操作控件添加装饰运动。
- 题图流程为 6.4 秒、几何推理为 5.6 秒、同步恢复为 5.2 秒；预定循环使用 CSS keyframes。
- 所有新增动画只改变 `transform` 和 `opacity`；移动使用强 ease-in-out，时间进度使用 linear。
- `prefers-reduced-motion` 下关闭所有新增动画，静态界面仍展示完整流程结果。
- 使用 `review-animations` 审查，无阻断项，结论为 Approve。

## 验证

- App 测试覆盖章节标题与三个场景标题。
- TypeScript、ESLint 和定向组件测试通过。
- Codex 内置浏览器在 485 px 窄屏和 1440×1000 桌面视口完成视觉验证；桌面场景无重叠，窄屏每个场景高度稳定为文字 300 px、演示 390 px 加间距。
- 页面可访问树中每个场景只出现一次，图示均提供中文 `aria-label`。

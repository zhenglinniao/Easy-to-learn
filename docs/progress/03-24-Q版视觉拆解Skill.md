# 节点 03-24：Q 版视觉拆解 Skill

## 用户确认的目标

- 输入内容应成为可爱、手绘、便于理解的分析图，而不是大段生硬文字。
- 内容简单且只有一个核心关系时可以单步；存在前置依赖、状态变化、因果链或多个推理台阶时使用多步。
- 数学题必须把准确的公式、几何或坐标信息与 Q 版手绘图结合，图解要说明解题动作和原因。
- 步骤按钮、KaTeX、动画和无障碍继续由前端统一负责，不接受模型生成的 HTML、CSS、SVG 或脚本。

## 实现

- 新增并默认启用 Prompt `v4`，保留 `v1`–`v3` 回滚能力。
- `v4` 的每一步必须包含至少一个 `diagram`，Domain Schema 会拒绝纯文字步骤。
- 新增安全 `comic-strip` DSL：最多 4 个面板，只允许受控主题图标、角色姿态、短标签、说明和色彩枚举。
- 前端用原创 Q 版“小易”绘制 point / think / cheer / observe 四种姿态，并支持单幅或短序列布局、深色主题和安全文本渲染。
- 数学图解优先使用：balance 表达等式两侧同步操作，magnifier 表达寻找条件，shapes 表达拆分组合，chart/coordinate-plane 表达变化；准确数学仍由 KaTeX、几何图和坐标图承担。

## 安全边界

参考提示词中的 `boardHtml`、内联 SVG、CSS 动画和模型生成按钮没有进入产品协议。模型只返回 Tutor DSL 数据，避免脚本注入、布局失控、按钮失效和 reduced-motion 缺失；前端负责实际视觉风格与交互。

## 验收结果

- Skill 官方快速校验通过。
- `pnpm check` 通过：22 个常规测试文件、105 个常规用例全部通过，生产构建通过。
- 真实 DeepSeek Responses API 黄金集通过方程、无问题番茄和 PNG 图文输入；方程用例额外要求每一步有图解，并同时包含准确 `math` 与 Q 版 `comic-strip`。
- Microsoft Edge 实测单格/双格漫画、KaTeX、上一步/下一步和 reduced motion；控制台 0 error、0 warning。
- 首次完整黄金集暴露番茄被降级为普通物体的问题，v4 已加入无明确问题的强类别路由并以同一真实用例复验通过。

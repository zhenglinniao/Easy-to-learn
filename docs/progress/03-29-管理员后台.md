# 03-29 管理员后台

## 完成内容

- 新增 `/admin` 管理页面，集中展示账户总量、本页暂停账户和启用模型数量。
- 支持从前端新增/移除 Provider，并动态调整启停、回退顺序、显示名称、Base URL、模型 ID、接口模式、结构化输出模式和超时；从下一次 Tutor 请求开始生效。
- 内置 SenseNova 6.8 Flash Lite 和 DeepSeek Flash 预设；API Key 采用只写输入，完整配置经 AES-256-GCM 加密后存入 Redis，概览只返回 `hasApiKey`。
- Base URL 强制 HTTPS 与服务端域名允许列表，阻断把管理配置变成内网 SSRF 跳板。
- 账户列表只返回脱敏邮箱、UUID、创建/登录时间、确认状态、暂停状态和画板数量。
- 支持可恢复的账户暂停与恢复；禁止管理员暂停自己，不提供立即永久删除入口。
- 所有管理接口同时校验 Supabase JWT、服务端 `ADMIN_USER_IDS` 白名单、允许的 Origin 和 Content-Type。
- 模型策略修改、账户暂停和恢复写入现有安全审计表，管理员和目标账户均使用 HMAC 摘要。

## 测试

- 模型配置覆盖默认值、动态新增、密钥保留、加密落库、域名限制、无密钥启用和超时预算拒绝。
- 管理 API 客户端覆盖 Bearer 令牌、PATCH 契约和无会话拒绝。
- 管理页面覆盖非敏感数据展示与账户暂停二次确认。
- 全量结果：36 个测试文件、152 个常规用例通过，5 个云端依赖用例跳过；生产构建、Lint 与类型检查通过。

## 部署配置

在 Vercel Production 环境增加：

```text
ADMIN_USER_IDS=<管理员在 Supabase Authentication Users 页面中的 UUID>
AI_ADMIN_ALLOWED_PROVIDER_HOSTS=<可选，额外批准的 Provider 域名，英文逗号分隔>
```

多个管理员使用英文逗号分隔。保存环境变量后重新部署，再用该账户登录并访问 `/admin`。商汤与 DeepSeek 已在内置允许列表中，不需要加入额外域名。不要填写邮箱、密码或 service role key。

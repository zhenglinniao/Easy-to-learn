# 阶段 3 / 节点 17：首页吉祥物与解释动效

## 状态

已完成。

## 设计边界

- 参考 Smart Canvas 页面“用视觉演示产品流程”的方法，但不复制其黑白配色、手写标题、左右舞台构图、功能卡片、拖拽便签、文案、图形或代码。
- 保留 Easy to learn 已有的暖色纸张、方格画布、衬线标题和珊瑚色强调体系。
- 新增原创吉祥物“小易”：以圆角画布精灵、纸张面孔、天线和铅笔手臂组成，不使用参考站的角色或素材。

## 动效决策

- 频率：官网首屏低频营销场景，可以使用克制的解释性动效。
- 目的：用漂浮、眨眼、指向和步骤进度说明“小易在题目与辅导板之间陪伴拆题”，不是纯装饰特效。
- 工具：预定循环使用 CSS keyframes，不引入动画依赖。
- 属性：只动画 `transform` 和 `opacity`；漂浮与指向使用 4.8 秒强 ease-in-out，步骤提示使用 6 秒 linear。
- 无障碍：角色包含中文可访问名称；`prefers-reduced-motion` 下关闭全部位移、缩放和眨眼动画，保留静态角色与说明。
- 高频画布操作、菜单、按钮和正文不增加入场动画。

## 响应式修正

- 真实浏览器检查桌面 1440×1000 与移动端 390×844。
- 移动端隐藏顶部重复的“打开画布”入口，保留正文主 CTA；品牌禁止换行，避免窄屏导航拥挤。
- 吉祥物和辅导板在窄屏重新定位，仍保持题目 → 小易 → 辅导板的阅读顺序。

## 验证

- App 组件测试覆盖吉祥物可访问名称和陪伴文案。
- Microsoft Edge 桌面、移动端和 reduced motion 实测通过，控制台 0 error、0 warning。
- 使用 `emil-design-eng` 完成整体质感决策、`animate` 完成动作构建，并用 `review-animations` 审查；结论为 Approve。

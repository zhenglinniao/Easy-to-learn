# 阶段 3 / 节点 13：版本冲突恢复

## 交付范围

- revision 冲突发生后立即停止自动同步，并在重新打开画板时继续识别持久化的冲突副本。
- 提供且只提供已确认的三条恢复路径：打开云端版本、本地版本另存为新画板、下载本地完整副本。
- 不提供强制覆盖云端操作，避免不可恢复的数据丢失。
- 本地版本另存时创建全新云画板，复制场景、辅导板和资产；同步失败后保留目标映射，重试不会重复创建画板。
- 打开云端版本时，先在内存中下载并校验全部远端资产，再通过单个 IndexedDB 事务切换快照、资产、outbox 和冲突状态。
- 下载完整副本不改变冲突状态，用户可在保留恢复选择的同时先取得离线备份。

## 数据安全

- 远端资产缺失、大小/MIME 不符或 SHA-256 不一致时拒绝切换，原本地冲突副本保持完整。
- 另存成功后只清理原画板的本地冲突缓存，新画板数据不受影响。
- 恢复操作繁忙时禁用三个入口，防止重复创建或并发切换。

## 设计工程

- 使用 `emil-design-eng` 组织恢复选项：推荐“另存为新画板”，但不弱化另外两条安全出口。
- 冲突属于低频、高风险决策，因此使用阻断式对话框和完整说明；不添加入场动画，只保留 120–140 ms 的按钮按压与状态颜色反馈。
- 错误信息保留在对话框内，失败不会关闭恢复入口。

## 验证结果

- 单元测试覆盖三条恢复入口、禁止强制覆盖、繁忙状态、冲突另存、目标复用、远端切换和资产未完整下载时的原子保护。
- 18 个测试文件、82 个用例通过。
- TypeScript、ESLint、Prettier、生产构建通过。

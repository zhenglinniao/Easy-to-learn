# 阶段 3.27：访问与用户统计

## 需求与设计

实现前先完成 `docs/06-访问与用户统计需求设计.md`。公开首页展示累计访问会话、近 30 天匿名访客和当前注册账户三项指标，不显示远端画板数量；不建设管理员分析后台，不采集来源、设备指纹、IP、题目或画布内容。

## 实现

- 新增服务端签发的随机 `HttpOnly` 访客标识，并以独立密钥 HMAC 后写入数据库；浏览器启用 DNT 时不发送访问事件。
- 新增日聚合和匿名访客摘要表。页面打开计入浏览量，同一访客连续 30 分钟内合并为一个会话。
- 新增访问写入和公开指标 API。写接口校验允许来源，读接口只返回非负聚合数并使用 5 分钟边缘缓存。
- 首页 Hero 后增加三项统计卡；加载时保持稳定骨架，接口失败显示“暂未连接”，不以零冒充真实数据，也不使用滚动数字动画。
- 公开聚合读接口允许本地 Vite 页面跨域只读访问正式指标；访问写入接口仍校验来源，本地调试不会污染生产统计。
- 匿名访客摘要保留 90 天并纳入现有保留任务；不可关联个人的日聚合计数长期保留。
- 更新隐私说明、环境变量示例、README 和数据库静态契约检查。

## 验证

- ESLint、TypeScript、Vitest、数据库静态契约和生产构建通过。
- Vitest：32 个文件、139 个常规用例通过；1 个真实供应商文件和 5 个外部用例按环境开关跳过。
- 数据库静态契约：8 张表、60 项 pgTAP 断言匹配。
- Playwright CLI + Microsoft Edge：1280px 三列、390px 单列、真实数值和降级状态通过，受控 API 响应下控制台 0 error、0 warning。
- 当前机器没有 Docker，未宣称本地 PostgreSQL pgTAP 实际执行通过；应用生产迁移前必须运行 `pnpm db:verify`。

- 状态：已完成
- 日期：2026-09-22
- 范围：画板 V2 快照、Tutor DSL V1、AI API 共享协议、统一错误、配额和账户删除状态

## 完成内容

- 按职责拆分 `constants`、`common`、`tutor`、`canvas`、`api`、`account` 和 `json-schema`，统一从领域包根入口导出。
- 实现 Tutor DSL 的 paragraph、math、list、callout 和受控 diagram 联合类型。
- 实现坐标系、几何图和流程图约束，包括坐标范围、数量边界、流程图引用、自环和重复边检查。
- 实现 Solve、Hint、Explain step 结果结构；Hint 强制恰好三级且 `hintLevel` 顺序为 1、2、3。
- 实现 Tutor 请求和响应协议，包括文字/图片输入、1.5 MiB 内联图片、选区范围、Explain step 父级上下文和固定 `zh-CN` locale。
- 实现每日 3 次配额结构以及文档定义的全部 API 错误码和固定 `retryable` 语义。
- 实现 V2 画板快照、持久化 appState、辅导板、资产清单、单资产 10 MiB、单画板资产 100 MiB、图片尺寸和 32 MP 限制。
- 实现账户删除五态和固定 7 天冷静期结构。
- 导出画板、Tutor 请求和 Tutor 结果的 Draft 2020-12 JSON Schema，供服务端和 AI 结构化输出共用。

## 边界决策

- Excalidraw 元素白名单与 0.18.1 正式元素联合类型对齐；元素内部字段由 Excalidraw 官方 `restore` 负责，领域层不复制 SDK 私有结构。
- 快照总 JSON 仍以 10 MiB 为硬边界。设计文档没有给出独立的元素数量数值，因此本节点不擅自增加第二个数量上限。
- Tutor DSL 所有自有对象使用严格 Zod object，拒绝模型额外输出 HTML、SVG、URL、脚本或未声明字段。
- “提示不得泄露最终答案”属于内容语义，不能靠结构 schema 准确判断；后续 AI 节点在 prompt、结果验证和测试 fixture 中执行该规则。
- API 错误 `details` 只接受标量记录；每个接口允许的字段白名单由对应 handler 在构造错误时进一步收紧，避免领域包虚构尚未定义的字段名。

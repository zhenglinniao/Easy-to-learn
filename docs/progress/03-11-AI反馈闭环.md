# 阶段 3 / 节点 11：AI 反馈闭环

## 交付范围

- 新增 `POST /api/ai/feedback`，同时支持游客匿名会话与登录 Bearer 身份。
- 反馈只接收 `requestId`、`rating: -1 | 1` 和可选预定义错误分类，不接收自由文本、题目或附件。
- 预定义分类固定为答案错误、解释不清、不安全内容和其他。
- 只允许反馈当前身份在 24 小时幂等缓存内真实完成的 AI 请求；模型、提示词和 Tutor schema 版本全部从服务端缓存提取。
- 使用 HMAC-SHA256 保存不可逆 actor 摘要，不在反馈表保存用户 ID 或匿名会话 ID。
- 数据库函数以 request ID 幂等更新评分；发生跨身份 UUID 冲突时拒绝更新，不覆盖原记录。

## 安全与数据保留

- API 校验请求方法、同源 Origin、JSON Content-Type、严格字段和枚举。
- `ai_feedback` 继续强制 RLS，浏览器角色无表权限；写入函数只授权 `service_role`。
- 反馈记录沿用已确认的 90 天保留策略，由运行数据清理任务删除。

## 验证结果

- 单元测试覆盖正常提交、服务端元数据、幂等更新、非法枚举、额外自由文本、身份越权和数据库冲突。
- 16 个测试文件、69 个用例通过。
- TypeScript、ESLint、Prettier 与数据库静态契约通过；数据库契约现含 43 项 pgTAP 断言。

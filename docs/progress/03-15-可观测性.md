# 阶段 3 / 节点 15：可观测性

## 状态

本地实现完成；真实 Sentry 项目、私有 source map 上传和告警通知待外部配置。

## 交付范围

- 浏览器启动时按 `VITE_SENTRY_DSN` 可选初始化 Sentry；未配置 DSN 时不发送任何监控事件。
- React 根节点增加错误边界，发生未处理渲染异常时显示中文恢复页，并允许用户重新加载。
- Sentry 关闭默认 PII，错误事件删除用户对象，只保留去除查询参数和片段后的 URL，不传请求正文、请求头或 cookie。
- 所有 Vercel API 通过统一 `sendError` 路径输出结构化 JSON 日志，字段固定为时间、级别、事件名、request ID、错误码、HTTP 状态和是否可重试。
- 服务端日志不记录错误消息、题目、画板内容、用户 ID、匿名会话、令牌或错误详情；4xx 为 warning，5xx 为 error。

## 设计说明

- 当前没有 Sentry 项目参数和上传凭据，因此继续禁止生成生产 source map，不能将本地初始化测试宣称为真实告警验收。
- 错误恢复页属于低频阻断状态，使用静态说明和单一恢复动作，不添加无助于恢复的动画。
- 性能追踪采样暂设为 0；在隐私审查和真实环境容量基线完成前，不采集画布操作轨迹。

## 验证

- 测试覆盖无 DSN 禁用、隐私配置、URL 脱敏、服务端日志字段白名单和 4xx/5xx 分级。
- TypeScript 与 ESLint 已通过；全量门禁结果记录在 `docs/04-单元测试报告.md`。

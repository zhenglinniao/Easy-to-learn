# 阶段 3 / 节点 12：游客迁移与本地数据

## 交付范围

- 游客点击登录保存时携带当前本地画板 redirect，登录后回到原草稿。
- 登录后的游客草稿始终先创建全新云画板，再复制快照和资产并按 revision 0 同步，不合并或覆盖已有云画板。
- 迁移记录保存源画板与目标画板映射；失败重试复用同一个目标，不重复创建云画板。
- 迁移成功后本地原稿保留 7 天，过期时自动清理；云端副本不受清理影响。
- 游客画布新增“本地数据”入口，支持打开其他本地画板、按画板删除、下载完整原始备份和清空全部本地数据。
- 删除单块画板会事务化清理关联图片、outbox 和冲突副本；清空操作覆盖全部 IndexedDB 恢复存储。

## 数据安全

- 单块删除和全量清空均有明确二次确认，不提供无提示删除。
- 全量清空确认文案先提示下载完整备份，作为 IndexedDB 故障和误操作的数据逃生通道。
- 迁移失败时保留游客原稿与迁移标记，并显示可操作错误，不把登录用户静默降级为游客。

## 设计工程

- 使用 `emil-design-eng` 控制数据管理界面的层级：普通打开、备份和危险操作分组，危险操作使用文本色与实心确认按钮区分权重。
- 数据列表与确认弹窗不添加入场动画；按钮只保留 120 ms 按压反馈。
- 窄屏工具栏禁止按钮文字被压缩成竖排，保持单行并允许横向滚动；本地数据弹窗已在窄屏实际浏览器中检查。

## 验证结果

- 单元测试覆盖新建目标迁移、失败重试复用目标、离线失败标记、7 天原稿清理、按画板删除和全量清空。
- 17 个测试文件、76 个用例通过。
- TypeScript、ESLint、Prettier、生产构建通过。
- 浏览器验证：游客登录 redirect 保留本地 ID；本地数据列表、删除二次确认和窄屏工具栏显示正常。

# 阶段 3 / 节点 7：AI 服务与配额

- 状态：实现完成；真实供应商联调待凭据
- 日期：2026-09-22
- 范围：匿名会话、游客/用户配额、幂等、临时图片票据、Gemini 代理、Tutor DSL 服务端校验与 HTTP 错误边界

## 完成内容

- 实现 30 天匿名会话，使用版本化 HMAC-SHA256 签名、常量时间校验和 24 字节随机会话 ID。
- Cookie 固定为 `HttpOnly; Secure; SameSite=Lax; Path=/`，响应不暴露匿名会话原始 ID。
- 登录身份使用 Supabase `auth.getUser(accessToken)` 服务端校验；登录画板通过用户 JWT 和 RLS 检查所有权。
- 游客只允许 `local_` 画板 ID；不能使用匿名身份访问云端画板。
- 实现 `Asia/Shanghai` 自然日每天 3 次配额，以及同 actor 每 5 分钟一次的原子窗口。
- Upstash Lua 在一个原子操作中完成日计数、时间窗和 requestId 预约；相同并发 requestId 不会重复调用模型。
- 输入校验失败、权限失败、供应商故障和超时不扣配额；模型已返回但两次均不符合 Tutor DSL 时计入已使用请求。
- 已验证结果提供 24 小时幂等返回；Redis key 只包含 HMAC actor 摘要，结果使用 AES-256-GCM 加密，不存储可读题目、图片或模型正文。
- Gemini 密钥只在 API 运行时读取，浏览器包不引用 SDK 或密钥；主模型固定 `gemini-3.6-flash`。
- Gemini 使用 `application/json`、TutorResult JSON Schema、固定中文 system instruction 和 30 秒取消超时。
- 服务端最多执行一次同模型格式纠错；两次结果都必须通过共享 Zod Tutor DSL，HTML、脚本、URL、未知 block 或越界 diagram 不能进入客户端。
- 模型返回的 metadata 不受模型信任，服务端覆盖为固定 model、prompt version 和生成时间。
- 实现内联 PNG/JPEG 与大图临时上传路径；临时对象按字节数、SHA-256、真实文件签名及真实尺寸重新验证。
- 应用层上传票据固定 10 分钟，且绑定 actor、requestId、MIME 和 object path；过期对象不能进入模型。
- 增加 `/api/anonymous/session`、`/api/ai/upload-ticket`、`/api/ai/tutor` 三个 Vercel Node handler。
- 所有写接口验证 Origin 和 Content-Type；错误统一映射为白名单错误码，不返回堆栈、内部路径或供应商正文。
- 增加 `.env.example`，明确区分浏览器公开变量与服务端秘密。

## 上传票据的供应商边界

Supabase 当前标准 signed upload URL 固定有效 2 小时，不能配置为 10 分钟。为保持已确认的产品契约，本实现额外使用 Redis 应用票据强制 10 分钟接受窗口：即使底层 URL 尚未自然失效，10 分钟后 Tutor API 也拒绝读取该对象，且 `ai-temp` 仍由 1 小时清理任务回收。

这不把产品票据延长为 2 小时，也不允许过期对象进入 Gemini。生产安全复核仍需确认 Supabase 项目的流量/存储滥用保护，因为供应商 URL 在应用票据过期后仍可能接受对同一路径的上传。

## 测试覆盖

- 匿名会话签发、篡改拒绝和 30 天过期。
- 相同 requestId 幂等返回且模型只调用一次。
- 同模型一次纠错、第二次非法输出拒绝。
- 五分钟请求间隔、每日三次上限和上海自然日零点重置。
- 超时退款、输入校验失败不扣配额和游客越权。

## 1. 项目与仓库

- 产品展示名称：`Easy to learn`。
- 代码仓库目录：`Easy-to-learn/`。
- 使用本地 Git 仓库，默认分支为 `main`。
- `excalidraw-master/` 只作为源码分析和 API 行为参考，不复制进新项目、不在其中开发业务代码。
- 新项目依赖发布版 `@excalidraw/excalidraw`，并通过 `canvas-adapter` 隔离。

## 2. 产品范围决策

- MVP 界面和 AI 输出语言均为简体中文（`zh-CN`）。
- 代码和数据结构保留 locale 字段，但 MVP 不制作英文或双语文案。
- 产品面向全年龄普通学习场景，不针对儿童画像、广告或个性化营销。
- 2026-09-23 扩展内容范围：画布选区不限于习题，可包含涂鸦、手写、文章、食物、蔬果、物体、流程、图表或混合内容。系统优先回答明确问题；没有问题时，从可识别内容推断一条主要教育拆解路径，并标记推断来源和置信度。
- 拆解采用轻松风趣的手绘视觉叙事方向，但准确性、可理解性、安全性和尊重优先；严肃、高风险或识别不确定的内容减少幽默。
- MVP 不收集出生日期；涉及未满当地法定年龄的注册用户时，注册条款要求监护人同意。生产发布前必须由数据/隐私负责人按实际运营地区复核。
- 默认不使用用户画板、题目或图片训练模型或改进产品。
- MVP 不建立包含用户题图的人工审核队列。错误反馈只记录评分、错误分类、模型版本和 request ID，不携带原始题目；以后若需要提交内容，必须新增显式、可撤回的 opt-in。

## 3. AI 配额与限流

- 游客：每个匿名会话每天最多 3 次有效 AI 请求。
- 登录用户：每个用户每天最多 3 次有效 AI 请求。
- 同一匿名会话或用户每 5 分钟最多发起 1 次有效 AI 请求。
- 日配额按 `Asia/Shanghai` 自然日 00:00 重置。
- 通过输入校验前的请求、客户端取消且尚未调用模型的请求、服务端故障和模型超时不扣配额。
- 已成功发往模型的请求计入配额；相同 `requestId` 的幂等重试不重复扣减。
- IP 和设备信号只用于辅助防滥用，不作为唯一身份键。
- 使用受限用途的 Upstash Redis 保存匿名会话、用户窗口计数和幂等结果；Redis 不保存题目、图片或模型正文。

## 4. 数据保留与删除

| 数据 | 保留规则 |
|---|---|
| 活跃画板和图片 | 保留至用户主动删除画板或账户；不设置自动过期 |
| 用户主动删除的画板 | 二次确认后立即从主数据库删除；关联对象存储在 24 小时内清理 |
| 游客本地画板 | 持续保存在当前设备，直到用户清理；产品提供按画板删除和清空本地数据入口 |
| 游客草稿登录迁移后的本地原稿 | 保留 7 天作为恢复副本，之后自动清理 |
| 账户删除冷静期 | 7 天；期间可以取消删除，账户进入待删除状态 |
| 冷静期结束后的主数据 | 24 小时内删除数据库记录和对象存储 |
| 已删除账户的系统备份 | 最长保留 30 天，只用于灾难恢复，不可用于日常查询；到期随备份轮换清除 |
| AI 运行元数据 | 90 天；只包含 request ID、用户/匿名标识的不可逆摘要、模型/prompt/schema 版本、耗时、token、费用和错误类型 |
| 安全与权限审计日志 | 180 天；不包含题目、图片、Base64、JWT、签名 URL 或密钥 |
| 匿名限流标识 | 最后活动后 48 小时清理；幂等响应正文不超过 24 小时 |

## 5. AI 模型决策

- 2026-09-23 用户确认不固定使用 Gemini API Key，本节原单供应商决策由多 Provider 配置取代。
- 服务端通过统一 `TutorModel` 接口支持 `gemini` 和 `openai-compatible`；后者用于 OpenAI、DeepSeek、通义千问、Moonshot、OpenRouter、Groq 和兼容服务。
- 部署时必须显式配置有序 Provider 链和精确模型名，不使用 `latest` 或 Preview 别名；所选模型必须支持题图所需的多模态输入。
- 只有超时、网络失败或供应商错误允许在单次业务请求内自动回退；模型成功返回后的内容错误不触发跨 Provider 回退，仍按原规则执行一次格式纠错。
- 每次结果必须记录实际 provider/model，并通过相同的 Tutor DSL、服务端 Zod 校验和客户端二次校验。
- 结构化输出按供应商能力配置为 `json_schema`、`json_object` 或提示词约束；无论供应商是否原生支持 JSON Schema，应用层校验均不可关闭。

## 6. 辅导交互决策

- `Solve`：生成完整教育拆解，不限于习题答案。习题保留求解路径；文章、食物、蔬果、物体、流程和图表按明确问题或默认学习目标拆解。
- `Hint`：一次 AI 请求生成 3 级提示，客户端逐级揭示；三级提示均不得直接给出最终答案。用户需要完整答案时单独使用 Solve。
- `Explain step`：位于辅导板当前步骤的操作区，针对指定步骤发起新请求；结果创建为与原辅导板关联的子辅导板，保留 `parentTutorBoardId` 和 `targetStepId`。
- 新辅导板默认采用 `follow-source`；用户拖动后仍保存相对来源选区的 scene 偏移。
- 辅导板不进入 Excalidraw 的撤销/重做历史。MVP 不实现跨 Store 事务历史；关闭辅导板属于明确的产品操作并立即持久化。
- viewport 只按画板保存在当前设备，不同步到云端，避免不同设备和屏幕尺寸互相覆盖。

## 7. 导出、删除与冲突

- 同时提供两种导出：
  - 标准 `.excalidraw`，作为通用逃生格式，不包含辅导板；
  - `.easy-to-learn.json`，包含 V2 场景、辅导板和资产 manifest。图片二进制以受控导出流程附带，不写入常规数据库快照。
- 删除画板采用二次确认后的硬删除，不增加回收站产品功能。
- revision 冲突时禁止直接覆盖云端，用户只能选择：
  1. 打开云端版本；
  2. 将本地版本另存为新画板；
  3. 下载本地完整副本。
- MVP 不提供“强制覆盖云端”。

## 8. Tutor DSL 与旧数据

- MVP 实现 `coordinate-plane`、`geometry`、`flow` 三类受控 diagram。
- 阶段 2 必须为每类 diagram 给出封闭 discriminated union、坐标范围、节点/边数量和样式白名单；禁止保留生产 `Record<string, unknown>`。
- V1 中的 HTML 辅导板永不执行或渲染。
- V1 迁移时保留原始文件作为只读、可下载的隔离备份；能可靠提取的纯文本可转成 paragraph，不能安全转换的辅导板跳过并显示兼容性通知。
- 成功保存 V2 前不得删除原始 V1 本地备份。

## 9. 工程选型

- Node.js：`24.21.0` LTS，使用版本文件和 CI 固定。
- 包管理器：`pnpm@11.25.0`，通过 `packageManager` 字段和 lockfile 固定。
- 产品领域状态：React reducer + Context；不额外引入全局状态库。
- 远端请求：TanStack Query；仅管理认证、画板列表和远端请求缓存，不接管 Excalidraw 场景。
- 本地持久化和同步：独立 repository/service + reducer 状态机，IndexedDB 使用版本化封装。
- 限流与幂等：Upstash Redis，仅由 Vercel Node Functions 访问。
- Schema：Zod 为单一事实来源，并导出 JSON Schema。
- 测试：Vitest、Testing Library、MSW、Playwright。
- 监控：Sentry + 服务端结构化日志；未配置凭据时本地开发使用禁用监控的适配器。

## 10. 基础设施现状

- 当前没有 Supabase、Vercel、Gemini、Google/GitHub OAuth、Sentry 或正式域名配置。
- 阶段 2 只设计环境和接口，不写入任何真实密钥。
- 阶段 3 可以先使用本地 Supabase、MSW/fixture AI 和 `.env.example` 开发。
- 真实 Gemini 集成测试、OAuth E2E、Preview 部署、监控验证和生产验收在对应凭据提供前保持阻塞，不能以 mock 结果宣称完成。

## 部署边界

`vercel.json` 依据 2026-09-23 可用的 Vercel 官方 Vite SPA、Project Configuration 和 Functions duration 文档编写，但当前没有 Vercel 项目与真实域名，尚未取得 Preview 响应头和 Cron 执行证据。

以下项目仍必须在真实 Preview/Production 环境完成：

- Supabase Auth/OAuth、RLS、Storage policy 与私有图片恢复 E2E。
- Upstash Redis 配额、一次性票据、幂等与 key expiry。
- 每个启用的 AI Provider 分别执行黄金题集、图片输入、结构化输出、回退、延迟、正确率、token 与成本告警验收。
- Sentry source map 私有上传和告警通知。
- 备份恢复、应用回滚、数据库 expand/migrate/contract 和账户删除演练。

在这些外部证据完成前，只能认定本地可运行 MVP 与部署配置已交付，不能认定生产发布完成。

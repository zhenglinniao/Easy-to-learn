## 主要交付

### AI 链路、模型治理与用量

- 管理员可配置 DeepSeek、SenseNova 文字模型和 SenseNova U1.5 Lite/Fast 生图模型；配置持久化、加密和刷新恢复均有回归覆盖。
- DeepSeek 使用 Responses + JSON Schema，SenseNova 文字模型使用 Chat Completions + 提示词约束；供应商按卡片顺序回退，并受整条请求总预算约束。
- 成功的 Tutor 响应增加安全的 `X-AI-Provider` 响应头，可在浏览器网络面板确认实际选中的供应商，不暴露题目、输出或密钥。
- 管理员不限额仍保持 `requestId` 幂等；普通登录账户每日 10 次，游客每日 3 次，图片额度独立。失败、超时或不可展示结果会退款。
- Redis 配额、幂等缓存、并发预留、过期租约和重复生图接管均改为原子或可恢复流程。
- 生图只针对适合视觉化的解题步骤执行；图片定位到具体步骤，带步骤标题、图注和替代文本，失败时保留文字与矢量讲解。
- “解释这一步”要求生成 2–4 个新的微步骤，并拒绝只改标题、复述原步骤的伪解释结果。

### 画布并发、反馈、保存与恢复

- AI 请求改为独立任务注册表，多个选择可并发执行；每个任务有独立进度、耗时、取消和插画状态，新请求不会取消旧请求。
- 增加“准备选区 / 生成答案 / 生成插画”动态反馈和任务坞，防止用户因无即时反馈而重复点击。
- 自动保存改为可串行 flush 的 latest-task 模型；页面隐藏、卸载和跨标签页竞争时仍会尽力落盘并恢复同步。
- 同步租约可续期，未获得租约、断网重连和指数退避不会永久卡住。
- 画板删除和远端冲突接管改为 IndexedDB 游标流式清理，避免把全部关联键装入内存并同时发出大量删除请求；用 64 条关联记录验证了目标清理和其他画板隔离。
- 完整本地备份会正确序列化 Blob，设置 100 MiB 上限；资产上传、水合、导入和来源校验均采用有界并发。

### 安全、隐私与运维

- 私有 API 统一 `private, no-store`；增加 HSTS、CSP、`nosniff`、frame/object 禁止等安全头。
- 管理员模型地址限制为允许的 HTTPS 域名，拒绝本地和内网地址；Cron 凭据常量时间比较，Bearer 格式和追踪 ID 均经过约束。
- 生成图片下载校验 MIME、大小、尺寸、像素总量和内容摘要，避免伪造或超大资产进入画布。
- 账户删除要求最近认证，管理员不能冻结或恢复其他管理员；临时上传、已删画板资产和账户删除任务都有租约与失败恢复。
- Git 跟踪文件密钥扫描已接入总门禁，只报告疑似密钥的位置，不回显值。
- CI 显式安装 Node `24.21.0` 和 pnpm `11.25.0`，避免仅安装 pnpm 后继续使用 runner 默认 Node 的漂移。

### 性能、包体与可用性

- 首页延迟加载 Sentry 和 Supabase SDK；画布数学渲染器与 KaTeX CSS 只在真正出现公式时加载，加载失败只回退到原始公式，不拖垮整个页面。
- 画布入口 JavaScript 相比优化前减少约 78 KiB gzip，画布首载 CSS 减少约 8 KiB gzip。
- Bundle 门禁现在读取 Vite manifest，递归统计画布路由的所有同步导入，避免只检查入口文件造成低估。
- 生产 manifest 不包含开发用 spike 路由，构建目录没有 source map，避免把诊断页面或源码映射带入发布物。
- 公开指标请求有 5 秒上限和结构校验，失败显示“暂未连接”；首页不展示远端画板数量。
- `@types/node` 更新到 26.6.3；生产依赖审计未发现 high 级别已知漏洞。

## 主要交付

### AI 链路与用量

- 修复模型输出不可用时仍扣除额度的问题。
- 管理员不限额仍保持 `requestId` 幂等，避免重复请求并发打爆 Provider。
- 对 Redis 配额、加密缓存、Tutor/Quota/Upload/Feedback/Illustration API 增加端点级契约测试。
- 保留并验证 DeepSeek、SenseNova、Gemini 适配器；补齐 Gemini 图文请求、超时、图片解析与故障转换测试。
- SenseNova 复用连接池，对瞬时断连/空响应进行有界重试；生图与文字任务保持独立。
- 图片结果按教学步骤定位，带有步骤标题、图注和替代文本；生图失败不会丢失文字/矢量讲解。
- 拒绝“换标题复述原步骤”的伪解释结果，要求新的 2–4 个微步骤。

### 画布并发、保存与恢复

- 将 AI 任务从单一全局请求改为独立任务注册表，支持多任务并发、各自取消、各自进度与独立插画状态。
- 增加“准备选区 / 生成答案 / 生成插画”动态反馈、耗时和取消入口，避免用户重复点击。
- 修复新辅导板在自动保存竞态中被旧快照覆盖的问题。
- 自动保存改为串行、可 flush 的 latest-task 模型；页面隐藏/卸载前尽力落盘。
- 修复同步退避定时器被 React effect cleanup 立即取消的问题，断网后联网会继续同步。
- 资产上传、资产水合和 Tutor 来源校验均使用有界并发，避免瞬间占满内存或网络。
- 修复“完整本地备份”中 Blob 被 JSON 静默序列化为 `{}` 的数据丢失；现在逐个转为 Base64，并设置 100 MiB 总量保护。
- 优化恢复/导出中的资产查找和 Base64 转换，从重复线性搜索改为 Map，并避免无界 `Promise.all` 峰值。

### 安全与运维

- 私有 API 统一 `private, no-store`，并增加 HSTS、CSP、`nosniff`、frame/object 禁止等响应头。
- 限制管理员模型地址为允许的 HTTPS 域名，禁止通过动态配置访问本地/内网地址。
- 对 Cron 凭据使用常量时间比较，收紧 Bearer 格式，清洗响应头中的请求追踪 ID。
- 管理员用户冻结/恢复阻止对其他管理员操作；账户删除要求最近认证并拒绝非法/未来时间戳。
- 临时 Tutor 上传加入过期清理；保留与账户删除管道的成功/失败路径都有回归测试。
- 生成图片下载验证 MIME、大小、尺寸、像素总量与内容摘要，防止伪造资产进入画布。
- 瞬时错误响应带标准 `Retry-After`，端到端保留 `X-Request-Id`，管理页面会显示追踪号。
- 新增 Git 跟踪文件密钥扫描门禁，发现疑似 API、GitHub、AWS 或 Slack 密钥时只报告文件和行号，不在日志中回显密钥内容。

### 性能、可用性和开发体验

- 延迟加载 Sentry、KaTeX 和 Supabase 浏览器 SDK，删除未使用的客户端依赖和生产 spike 路由。
- 建立首包 JS/CSS/总资产预算校验，避免后续体积回归。
- 公开指标请求增加 5 秒上限与返回结构校验，失败明确显示“暂未连接”。
- 可选分析和监控失败不再污染主业务，且会在会话内抑制重复失败请求。
- 对话框增加焦点围栏和 Escape 恢复；AI 计时视觉反馈不再让读屏器每秒重复播报。
- 新增 GitHub Actions 质量门禁，统一 peer/lint/type/test/DB 契约/build/bundle/format 校验。
- 更新已验证的补丁依赖；安全审计未发现 high 级别已知漏洞。

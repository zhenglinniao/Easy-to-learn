| 模块 | 正常场景 | 边界场景 | 异常场景 |
| --- | --- | --- | --- |
| Domain | V1/V2、Solve、Hint、Explain step 合法结构 | 快照体积、步骤索引、资产总量与重复哈希 | 非法 DSL、Base64、元素类型和 schemaVersion |
| Canvas Adapter | 文字/视觉选区、坐标往返、来源移动 | 空选区、仅移动不改变 hash、缩放改变 hash | 来源修改 stale、删除 orphaned |

| AI 反馈 | 评分、分类与服务端模型元数据 | 重复 requestId 幂等更新 | 非法枚举、自由文本、跨身份请求与 UUID 冲突 |

## 本阶段发现并修复的问题

多标签页协调器原协议在两个 writer 同时竞争时，会在收到对方 `claim` 后再次发送 `claim`，形成循环广播。现改为 `claim + ack` 单向握手：`ack` 只登记竞争者、不再触发回应；竞争结果仍按 writer ID 确定且只有一个租约成功。

## 本地真实浏览器冒烟验收

2026-09-23 使用 Playwright CLI 驱动 Microsoft Edge 验证以下流程：

- 官网进入游客画板，路由生成并固定本地画板 ID。
- 创建文字题目 `2x + 3 = 11`，再次点击选中后出现 Solve / Hint 菜单。
- Solve 准备阶段正确识别 1 个元素和 11 个文字；因本地没有 API 凭据，不把模型返回计为通过。
- 刷新页面后同一文字元素从 IndexedDB 恢复，重新选择仍出现 AI 菜单。
- 本地数据面板列出当前画板；完整备份成功下载并解析为 `easy-to-learn` exportVersion 1，其中 Canvas schemaVersion 为 2 且包含 1 个文字元素。
- 整个流程浏览器控制台 0 error、0 warning。

该记录是可复现的真实浏览器冒烟证据，但不替代开发文档要求的 CI 自动化 E2E 和真实供应商验收。
